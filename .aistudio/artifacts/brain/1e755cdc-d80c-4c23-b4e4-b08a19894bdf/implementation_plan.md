# پلانی جێگیرکردنی یاریدەدەری زیرەکی دەستکردی Gemini بۆ خاوەن کار (GARDI ERP)

ئەم بەڵگەنامەیە پلانی ئەندازیاری و هەنگاوەکانی جێگیرکردنی چاتبۆتی زیرەکی Gemini پیشان دەدات کە بە تایبەتی بۆ خاوەن کار (Admin) دادەنرێت لە شاشەی سەرەکی داشبۆرد بۆ شیکاری دارایی، فرۆشتن، کۆگا و قەرزەکان.

---

## ١. پوختەی پێداویستییەکان و بڕیاری بەکارهێنەر
* **ئاستی دەسەڵات:** تەنها و تەنها بۆ خاوەن کار / بەڕێوەبەر (Admin/Owner) دەبێت بە پارێزراوی تەواو لە ڕێگەی مۆڵەتی `permission:users.manage`.
* **شوێنی دەرکەوتن:** دوگمەی سەرئاوکەوتوو (Floating Action Button) لە شاشەی سەرەکی داشبۆردی ئەدمین (`AdminDashboardScreen`).
* **شێوازی گفتوگۆ:** نووسینی دەقی ڕاستەوخۆ (Text Input) بە زمانی کوردی سۆرانی بە ڕووکارێکی مۆدێرن و ڕێکخراو.
* **مەودای شیکاری و زانیاری:**
  1. ئامار و قازانجی پوختەی فرۆش و داواکارییەکان
  2. ئاماری کۆگا و کەمی کاڵاکان (Low Stock)
  3. قەرزی کڕیارەکان و باڵانسی قەرزی کۆمپانیا
  4. شیکاری کارکردن و فرۆشی مەندوبەکان

## ٣. هەنگاوەکانی جێبەجێکردن (Implementation Steps)

### قۆناغی یەکەم: لایەنی سێرڤەر (Laravel Backend)
1. **دروستکردنی خزمەتگوزاری یاریدەدەر (`GeminiAssistantService.php`):**
   * پەیوەستکردنی بە خزمەتگوزاری فەرمی ڕاپۆرتەکان (`ReportService`).
   * ئامادەکردنی پوختەی داتاکانی ئەمڕۆ، ئەم هەفتەیە، و ئەم مانگە (کۆی فرۆش، قازانج، باڵانسی قەرزەکان، مەندوبە چالاکەکان، کاڵا کەمبووەکانی کۆگا).
   * بەستنەوەی پارێزراو لەگەڵ Google Gemini API بە مۆدێلی هاوچەرخی پەسەندکراو بە بەکارهێنانی کلیلی سێرڤەر لە `.env`.
   * دانانی ڕێنمایی ورد (System Prompt) کە بە زمانی کوردی پاراو و ژمێریارییانە وەڵام بداتەوە و داتای دەرەوەی سیستمەکە نەهێنێتە پێشەوە.
2. **دروستکردنی کۆنتڕۆڵەر (`GeminiAssistantController.php`):**
   * وەرگرتنی پرسیاری ئەدمین و پشکنینی دروستی داتا (Validation).
   * گێڕانەوەی وەڵامی شیکاری کراو لە شێوەی JSON.
3. **تۆمارکردنی ڕێڕەوی پارێزراو لە (`backend/routes/api.php`):**
   * زیادکردنی خاڵی پەیوەندی `POST /api/v1/ai/assistant/chat` لەژێر مایکرۆسیستەمی `permission:users.manage` بۆ ئەوەی هیچ ڕۆڵێکی تر جگە لە ئەدمین نەتوانێت دەستی پێی بگات.

### قۆناغی دووەم: لایەنی ئەپڵیکەیشن (Flutter Client)
1. **دروستکردنی مۆدێل و پرۆڤایدەر (`ai_assistant_provider.dart`):**
   * بەڕێوەبردنی بارودۆخی پەیامەکان (نامەی بەکارهێنەر، وەڵامی بۆت، دۆخی چاوەڕوانی Loading، دۆخی هەڵە).
   * پەیوەندی لەگەڵ API لە ڕێگەی `ApiClient` بە تۆکنی فەرمی.
2. **دروستکردنی ڕووکاری چاتی سەرنجڕاکێش (`admin_ai_assistant_dialog.dart`):**
   * دیزاینێکی خاوێن و شایستە بە زمانی کوردی و پیتەکانی Rudaw.
   * دانانی دوگمەی خێرا (Quick Suggestion Chips) بۆ پرسیارە باوەکان (وەک: *"کۆی فرۆشی ئەمڕۆ چەندە؟"*, *"کام کاڵایە لە کۆگا خەریکە تەواو دەبێت؟"*, *"قەرزداری سەرەکی کێیە؟"*).
   * نیشاندەری نووسین و دۆخی بیرکردنەوەی ژیر (Thinking / Typing Indicator).
3. **بەستنەوە لەگەڵ شاشەی سەرەکی ئەدمین (`AdminDashboardScreen`):**
   * زیادکردنی دوگمەی سەرئاوکەوتوو (FloatingActionButton) بە ئایکۆنی Auto Awesome / AI و ڕەنگی تایبەتی سیستم بۆ کردنەوەی پەنجەرەی چاتەکە.

## ٤. سەلامەتی و یەکپارچەیی داتاکان (Safety & Data Integrity)
* **تەنها خوێندنەوە (Read-Only):** بۆتەکە تەنها دەسەڵاتی شیکاری و خوێندنەوەی داتای هەیە، و هیچ فەرمانێکی سڕینەوە، دەستکاریکردنی نرخ، پارەدان یان گۆڕینی داتابەیس جێبەجێ ناکات.
* **نەهێنانی داتای خەیاڵی (Zero Hallucination):** وەڵامەکان لەسەر بنەمای ژمارە و حیساباتە حەقیقییەکانی `ReportService` دەبن.
* **پاراستنی نهێنییەکان:** کلیلی API لەسەر مۆبایل نامێنێتەوە و لەسەر سێرڤەر بە پارێزراوی هەڵدەگیرێت.

---

## ٥. شێوازی تاقیکردنەوە و پشتڕاستکردنەوە (Verification Plan)
1. **پشکنینی ئاسایش و دەسەڵات:** دڵنیابوونەوە لەوەی تەنها بەکارهێنەری خاوەن مۆڵەتی `users.manage` دەتوانێت داواکاری بنێرێت.
2. **پشکنینی گەڕانەوەی وەڵام:** تاقیکردنەوەی پرسیار لەسەر فرۆش، قازانج و کۆگا بە زمانی کوردی و دڵنیابوون لە ڕاستی ژمارەکان بە بەراورد بە داتای فاکتۆرەکان.
3. **پشکنینی UI لەسەر مۆبایل و تابلێت:** دڵنیابوون لەوەی دیالۆگ و پەنجەرەی چاتەکە لەسەر هەموو شاشەکان جوان دەردەکەوێت و کیبۆرد بەربەست دروست ناکات.
